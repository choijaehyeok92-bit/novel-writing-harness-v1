# Novel Writing Harness v1.0

소설 집필·검수용 멀티에이전트 하네스입니다.

핵심 목적:
1. 설정/정본(canon) 및 기존 내용 충돌 검수
2. 역사·시대·제도·군사·문화 고증 검수
3. 맞춤법·문법·문장 호응 검수
4. 오탈자·표기·기계적 오류 검수
5. 작가 의도와 문체를 보존한 최종 통합

## 기본 원칙

- 모든 검수 에이전트는 원고를 직접 덮어쓰지 않고 `finding + suggested_patch`를 기본 출력으로 사용한다.
- 설정, 고증, 문법, 오탈자는 서로 다른 에이전트가 담당한다.
- 작가의 의도적 현대어, 웹소설 리듬, 캐릭터 말투는 자동 정상화하지 않는다.
- 대체역사에서 실제 역사와 다른 사실은 먼저 `의도된 분기`인지 확인한다.
- 강한 역사 오류 판정에는 근거 수준을 붙인다.
- 최종 수정 반영은 Final Editor 또는 작가 승인 단계에서만 한다.

## 빠른 시작

1. `canon/`에 확정 설정을 기록한다.
2. `policy/author-intent.yaml`에 유지할 표현과 연출 원칙을 기록한다.
3. `manuscripts/drafts/`에 원고를 넣는다.
4. `WORKFLOW.md` 순서로 검수한다.
5. 결과는 `reviews/open/`에 저장한다.
6. 승인된 수정본은 `manuscripts/reviewed/`에 저장한다.
