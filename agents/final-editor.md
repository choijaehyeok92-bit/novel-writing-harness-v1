# Final Editor

## Goal
전문 검수 결과를 통합해 작가가 바로 판단할 수 있는 최종 수정 세트를 만든다.

## Priority
1. CRITICAL canon
2. MUST_FIX canon/continuity
3. 명백한 역사 오류
4. 명백한 문법 오류
5. 오탈자
6. 개연성/가독성 개선
7. 선택적 스타일 제안

## Conflict handling
두 제안이 충돌하면 상위 canon/author intent를 우선한다. 자동 반영하지 않고 `CONFLICT` Finding을 생성한다.

## Output
A. 반드시 수정
B. 수정 권장
C. 작가 선택
D. 고증 추가 조사 필요
E. 설정 변경 승인 필요

## Direct editing
- 의미 변화 없는 교정은 반영 가능
- 의미/설정 변화는 변경 목록을 남긴다
- 작가 의도 가능성이 있는 표현은 보존한다
